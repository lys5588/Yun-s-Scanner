# 高斯重建

## 1. 目的与输入输出

使用共享的 Swift/Metal 训练器，将有真实相机内参与位姿的图片、初始化点云转换为 3D Gaussian Splatting 模型。输入为扫描目录的 `images/`、位姿 JSONL 与 `points.ply`；普通视频先完成摄影测量，不能补造 ARKit 位姿或 LiDAR 深度。

完成后在 `gaussian-training/model/` 发布 `gaussians.sog`、标准 GS `gaussians.ply`、`gaussians.json`、`experiment.json`、`training-report.json`、`training-poses.jsonl`。按配置附带 `ppisp.json`、预览图，视频模型保留 `video-import.json` 的任意尺度声明。初始化点云不是训练模型。

## 2. 实现入口与约定

Mac 由页面调用 `tools/run_mac_training.sh`，再进入 `tools/train_gaussians.swift`；iPhone 由 `Training/UI/GaussianTrainingView.swift` 经 `Training/UI/TrainingCenter.swift` 管理 `GaussianTrainingSession`；共享的 `Background/ContinuedProcessingLease.swift` 负责持续后台请求与实际授权状态。以下训练文件均位于 `arkit-3dgs-scanner/Training/`：

- `TrainingDataset.swift`：选择图片、加载相机与种子点，原始输入保持不变。
- `GaussianTrainer.swift`、`GaussianRasterizer.swift` 与 Metal 内核：投影、梯度、优化和高斯增密。
- `TrainingMemoryPlan.swift`、`GaussianCheckpoint.swift`、`TrainingWorkspace.swift`：内存预算、恢复状态和发布目录。
- `GaussianExport.swift`、`GaussianSOG.swift`：模型及可追溯记录。

Quick 基础值为长边 960、4,000 次迭代、最多 300,000 高斯、SH 2 阶，图片不放大。Mac CLI 使用明确指定的迭代数；手机自动迭代数为 `max(4000, ceil(训练照片数×12/1000)×1000)`，也可手动设置。内存计划及增密策略会限制实际高斯数，不能把配置上限写成实测数量。Mac 普通视频训练脚本明确关闭深度种子、深度损失、再次位姿精修和 PPISP；App 新增视频入口通过 `video-import.json` 识别普通视频，新训练显式关闭深度种子/损失与再次位姿精修，PPISP 默认关闭（用户可启用），Mip 保留；恢复检查点不改已有配置。准备任务仍在取消排空时拒绝启动训练，避免同一设备资源竞争。下述早期模拟器实验配置按当时实测保留，不倒改为新默认值。

内存计划约束模型、交叉列表、图片缓存和保存空间；手机监测内存、温度、电量及后台 GPU 权限，必要时暂停并尝试保存检查点。训练后台执行需设备开放后台 GPU、签名带有所需 entitlement，且当前 `BGContinuedProcessingTask` 已实际获准；提交申请成功不等于后台可用。显示获准状态后可以切换其他 App，后台不再更新实时预览，保留训练与任务进度。缺少授权时切后台尝试写检查点后暂停，回前台由用户继续；系统取消或任务到期即使在前台也暂停。强制结束 App 无法持续执行，只能依赖已完整写出的检查点恢复，不能保证最后未保存的迭代不丢失。

检查点携带优化状态与配置，恢复前检查当前内存能否容纳；Mac 页面的“继续训练”从准备好的输入重新开始，不承诺迭代级恢复。模型先写临时目录，全部成功后发布；失败不标为完成，原模型和原始输入保留。

本轮当前 Personal Team 的 Background GPU Access 签名被 Xcode 拒绝，默认个人版本不具备持续后台 GPU 训练权限，切后台使用检查点暂停路径。`Config/BackgroundGPU.entitlements` 保留可选权限配置，只有适用的签名 Team、运行设备能力和实际任务授权均满足才能启用。后台能力、任务授权及进度事件在 `Documents/background-processing.json` 记录，不能用 Mac GPU 测试推定手机已获授权。

完成后的“分享 3DGS 模型”先选择 SOG 或 PLY。`TrainingWorkspace.makeModelArchive(format:)` 生成对应 ZIP，只携带所选模型文件并同步包内元数据的格式声明；相机、视频尺度来源、PPISP 和原实验记录保留，源模型不变。实验记录中的 outputs 描述当时训练生成的完整产物，分享选择不会改写这段历史。SOG-only 导入模型不能还原原始 PLY，界面禁用未保存格式，底层同样拒绝请求。

`GaussianMetal.swift` 将 `MTLBuffer.contents()` 放到泛型数组复制闭包外，规避本机 Swift 6.4 优化编译导致的错误返回值损坏；保持优化构建和原有数据布局。

## 3. 验证方法

`bash tools/test_gaussian_training.sh` 验证 GPU 前向与 CPU 参考、有限差分梯度、损失/PPISP、合成训练、保存和恢复，并检查真实扫描 CLI 能编译。真实视频另需检查完整输出、实际耗时/内存、几何与颜色、重开和模型导出；这些结果随实验记录保存。iPhone 必须另外验证正常前台训练、获准后的后台持续、授权拒绝、系统取消/到期和检查点恢复；后台场景需记录实际 grant 和进度，不能只看提交调用返回。

Mac CLI 的 `--enhance-from MODEL --iterations 0` 可用于重载已有模型并评估，不增加训练迭代；省略 `--save-model` 不重写模型。`--view-metrics`、`--dump-views` 和 `--dump-ids` 现在在 `--align-eval 0` 时也导出原验证相机的 CSV/PNG；正数才使用测试时相机对齐。SOG 优先于 PLY，单独验证 PLY 时必须使用不含 SOG 的模型目录。普通视频的训练日志依据已验证的非米制声明显示 `units`，不再将归一化距离标成米。

## 4. 实际结果与限制

2026-10-23，本机 Mac mini M4／16 GB、Xcode 27.1／Swift 6.4、Metal 27A266a：完整脚本退出码为 0，优化版 28 项光栅化、10 项损失/PPISP、85 项训练检查，以及 CLI 编译与用法检查全部通过。覆盖模型导出重载、检查点恢复和 1,200 帧合成扫描内存回归。日志为 `.build/verification/gaussian-training.log`。

真实视频实验 `local-data/runs/20261023-002145-0965a5f9/` 已完成：87 个训练视角、12 个验证视角、8,033 个初始化点，540×960、SH 2、4,000 次迭代，关闭深度种子/损失、位姿优化与 PPISP。实际训练 107.0 秒、跳过 0 次，最终 299,708 个高斯，验证 PSNR 24.663 dB、SSIM 0.8544；训练采样峰值物理内存 419 MiB，导出前进程历史峰值 447 MiB。完整模型原子发布，包含 SOG、标准 PLY、配置、实验、训练报告、99 个相机和原视频转换来源。

新编译的 CLI 分别重载 SOG 和 PLY，各新增 0 次训练迭代，不进行测试时相机对齐。训练分辨率的 PLY 指标与导出前一致；SOG 为 PSNR 24.408 dB、SSIM 0.8535。原照片分辨率 900×1600 的 PLY/SOG 平均 PSNR 分别为 24.451/24.202 dB；全部 12 个验证视角 PNG、CSV 和命令保存在实验的 `model-qa/`。主要结构和颜色一致，但高频细节、细线和部分椅子区域仍模糊；不能把一次流程成功当作高质量重建已经全面验收。

同一真实准备输入另在 iPhone 18 Pro 模拟器（iOS 27.0）通过 App 界面完成训练：102 张图片的哈希，以及位姿、点云和来源清单均与 Mac 输入一致；App 选取 99 张，排除 ID 17、24、39。界面选择 Quick，关闭位姿优化及 PPISP，实际配置为 540×960、SH 2、4,000 次、`holdOutEvery=0`。深度选项仍为默认值，但输入没有 depth/confidence 文件，因此没有深度种子或深度监督；不能写成配置已显式关闭。全部 99 张用于训练，0 张留出，不能将其结果当作 Mac 的独立验证指标。

模拟器最终状态为 `completed`，实际 4,000 次、299,708 个高斯，模型保存成功。记录耗时 183.7 秒；训练报告采样峰值为 306 MiB，最终状态为 345 MiB（保存阶段继续采样）。这些数值只记录本次模拟器运行，不代表手机性能。`TrainingFinal.xcresult` 已验证真实界面设置与启动；`CompletedModel.xcresult` 已验证重启 App 后从历史打开保存模型、显示完成统计、拖动和重置视角，均位于 `.build/simulator-ui-validation/`。实验下 `simulator-training/` 用于保留模型、状态、选帧和输入来源。

本次模拟器训练从 Mac 已准备好的真实扫描开始，不覆盖手机直接视频摄影测量。尚无手机训练耗时、峰值内存或热行为实测；Mac、模拟器与合成测试不能替代手机采集、训练和显示验收。

普通视频归档的 CPU 回归通过实际 `ScanLibrary.archive` 验证 PLY 非公制标记、相机/点云一致旋转、来源清单保护、无效清单拒绝与原 ARKit 行为。命令为 `bash tools/test_prototype_training.sh`，当前共 17 项通过。

2026-10-23 模型分享 CPU 回归通过：显式 SOG/PLY 打包、实际重新导入、相机与任意尺度保留、PPISP/实验原文保留、缺失格式拒绝、失败不覆盖既有归档及删除清理。结果在 `.build/feature-reconstruction-20261023/share-test.log`。这些回归不执行手机 GPU；本轮持续后台训练实现仍待真机逐项验收。
